Getting data in and out

Getting data in and out

Spreadsheet import, exports, distributing to a fleet, the catalogue server and updates.

Importing a spreadsheet

Almost every business already has its parts in a spreadsheet. Studio imports CSV and Excel files with a column mapping step: it reads your headings, works out what each column is and what type it holds, and lets you correct it.

It handles the things that usually break an import — a heading row that is not the first row, mixed date formats, currency symbols, decimal commas — and it tells you exactly what it is about to do before it does it:

5 to add, 0 to update, 0 rows skipped, 0 cells left empty — and then, plainly, 5 added, 0 changed, 40 removed. You see the removals before you agree to them.

You can replace a catalogue outright, or merge a newer price list into the one you already have without doubling anything up.

Exporting your catalogue

RouteWhat it means
Plain exportAn ordinary readable file. Your data, yours to keep, openable by anything. Any stored credentials are stripped out of it
Sealed exportEncrypted to the specific handsets you name. Only those devices can open it
BundleThe catalogue together with its photographs and drawings, in one archive
Catalogue serverHandsets fetch updates themselves over your own network

Exports are named after the catalogue and the date, so a folder of them can be read at a glance.

There is no lock-in. The plain export is a readable document you can keep, archive or move elsewhere. That is deliberate: a format only our software can read would be lock-in wearing a security badge.

The catalogue server

An optional extra for larger fleets. Studio exports a small, ready-to-run program for Windows, Linux or a Raspberry Pi, together with its configuration and its key.

Put it on a machine in your building, and every handset picks up catalogue updates over your own network — no web host, no hosting bill, nothing exposed to the internet.

What it does and refuses

  • The connection is pinned: handsets accept that one machine and no other, so nothing on the network can impersonate it.
  • It refuses any request that does not carry the shared secret it was issued with.
  • It will not serve its own key, will not list a directory, and serves nothing except the catalogue.
  • It mints its own certificate on first run. There is nothing to configure and no certificate to buy.

Once bought, Export catalogue server appears in Studio under Settings ▸ Catalogue. Before it is bought the row is absent rather than greyed out, because a permanently dead control is an advertisement wearing a control's clothes.

Catalogue updates

A catalogue can name an address it updates from — your catalogue server, or any https address you control. Handsets check on their own, at an interval you set, no more often than every fifteen minutes.

An update is offered, never applied behind somebody's back. A fetched catalogue goes through the same preview, signature check and confirmation as a file handed over by hand — mid-shift, on somebody's phone, is not the moment to change what the app says.

A source offering an older catalogue than the handset already holds is refused, and the message says who has to act.
